Savorly Cooking Journal

React · TypeScript · Vite · Node.js · NVIDIA Nemotron

A personal cooking journal for recording recipes, notebook pages, photos, and cooking experiments.

View repository Watch demo

Recipe and notebook organization

Record recipes and attempts, organize notebook content, and export recipe or notebook PDFs.

Meal planning

Plan meals and scale grocery quantities according to recipe servings.

AI cooking assistant

Use NVIDIA Nemotron through Nebius Token Factory for recipe-context questions, draft recipes, and ingredient substitutions. A Node.js backend handles provider requests, keeping the API key out of frontend code.

Implementation

The repository includes automated checks for application logic and AI request handling, alongside a Node.js API backend and a React frontend.
