Savorly Cooking Journal

React · TypeScript · Vite · Node.js · NVIDIA Nemotron

A personal cooking journal for recording recipes, notebook pages, photos, and cooking experiments.

View repository Watch demo

Project Description

Savorly is a personal cooking journal built with React, TypeScript, and Vite, with a Node.js backend for AI requests. It brings together recipe notebooks, meal planning, grocery lists, and PDF export. An NVIDIA Nemotron-powered assistant through Nebius Token Factory supports cooking questions, recipe drafts, and approximate nutrition estimates. The app also includes a separate toddler journal workspace.
